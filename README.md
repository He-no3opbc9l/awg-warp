# awg-warp

Двойной туннель **AmneziaWG + Cloudflare WARP** для обхода блокировок.

```
Клиент → AWG-туннель → VPS → WARP-туннель → Cloudflare → Интернет
```

> **Примечание:** совместимо с уже установленными AWG-серверами. Если на VPS уже запущен AWG-интерфейс (awg0, awg1 и т.д.), скрипт создаст новый интерфейс (awg2, awg3 и т.д.) для работы с WARP.

## Установка

```bash
git clone https://github.com/He-no3opbc9l/awg-warp.git
cd awg-warp
bash init.sh install
```

Запущенный без флагов в терминале, установщик **задаст три вопроса** (Enter — значение по умолчанию):

```
Порт AWG-сервера (Enter — случайный):
Версия протокола AmneziaWG (1/2, Enter — 2):
Использовать WARP-туннель? (Y/n):
```

- **Порт** — пусто = случайный (автовыбор с 39548), либо свой номер 1–65535.
- **Версия** — `2` (по умолчанию) или `1`, см. ниже.
- **WARP** — `Y` (по умолчанию) — двойной туннель; `n` — прямой выход в интернет.

### Неинтерактивная установка (флаги)

Любой заданный флаг **отключает соответствующий вопрос**. Если запуск не в терминале (`curl … | bash`, cron) — вопросы пропускаются и берутся значения по умолчанию.

```bash
bash init.sh install --port 27015 --awg-version 2        # свой порт, версия 2, WARP (дефолт)
bash init.sh install --no-warp                           # без WARP, прямой выход
bash init.sh install --no-warp --awg-version 1           # без WARP, версия 1.0
```

| Флаг | Описание |
|------|----------|
| `--port <порт>` | Кастомный порт AWG-сервера (по умолчанию — случайный, с 39548) |
| `--no-warp` | Без WARP: `Клиент → AWG → VPS → Интернет` |
| `--warp` | Принудительно с WARP (пропустить вопрос) |
| `--awg-version <1\|2>` | Набор параметров обфускации (по умолчанию — `2`) |

### Версия протокола AmneziaWG

По умолчанию — **2.0**: `S3`, `S4`, диапазоны `H1–H4` и DNS-сигнатура `I1` поверх базовых параметров 1.0 — более стойкая обфускация против DPI. Версия **1.0** (`Jc, Jmin, Jmax, S1, S2, H1–H4`) — для максимальной совместимости со старыми/сторонними клиентами.

> ⚠️ Параметры 2.0 понимает только **свежий** билд AmneziaWG в клиенте. Если клиент знает только 1.0 — он не подключится к 2.0-серверу; тогда ставь версию `1`.

Скрипт автоматически:
- Установит Go, amneziawg-go, awg-tools
- Развернёт `awg-manager.sh` в `/etc/amnezia/amneziawg/`
- Поднимет WARP-туннель (если не выбран режим без WARP) и инициализирует AWG-сервер (публичный IP определяется автоматически)

## После установки — 2 шага

### Шаг 1 — Создать пользователя

```bash
bash /etc/amnezia/amneziawg/awg-manager.sh -c -u <имя>
```

### Шаг 2 — Получить конфиг

```bash
bash /etc/amnezia/amneziawg/awg-manager.sh -q -u <имя>   # QR-код
bash /etc/amnezia/amneziawg/awg-manager.sh -p -u <имя>   # текстовый конфиг
cat /root/awg-warp/<имя>.conf                             # скопировать конфиг напрямую
```

## Управление пользователями

Все команды выполняются через `/etc/amnezia/amneziawg/awg-manager.sh`.

### Создать пользователя

```bash
bash /etc/amnezia/amneziawg/awg-manager.sh -c -u <имя>
```

Конфиг пользователя будет сохранён в `/root/awg-warp/<имя>.conf`.

### QR-код для подключения

```bash
bash /etc/amnezia/amneziawg/awg-manager.sh -q -u <имя>
```

### Вывести конфиг

```bash
bash /etc/amnezia/amneziawg/awg-manager.sh -p -u <имя>
```

### Удалить пользователя

```bash
bash /etc/amnezia/amneziawg/awg-manager.sh -d -u <имя>
```

### Заблокировать / разблокировать

```bash
bash /etc/amnezia/amneziawg/awg-manager.sh -L -u <имя>   # заблокировать
bash /etc/amnezia/amneziawg/awg-manager.sh -U -u <имя>   # разблокировать
```

## Опции awg-manager

| Флаг | Описание |
|------|----------|
| `-i` | Инициализация сервера (ключи и конфиг) |
| `-c` | Создать нового пользователя |
| `-d` | Удалить пользователя |
| `-L` | Заблокировать пользователя |
| `-U` | Разблокировать пользователя |
| `-p` | Вывести конфиг пользователя |
| `-q` | Вывести QR-код пользователя |
| `-u <user>` | Имя пользователя |
| `-s <host>` | Внешний IP/домен сервера |
| `-N <name>` | Имя AWG-интерфейса (по умолчанию auto: awg0, awg1…) |
| `-P <port>` | Порт AWG-сервера (по умолчанию auto, начиная с 39548) |
| `-V <ver>` | Версия параметров обфускации AmneziaWG: `2.0` (по умолчанию) или `1.0` |
| `-I <iface>` | Сетевой интерфейс сервера (по умолчанию auto) |

## Полное удаление awg-warp

```bash
bash init.sh remove
```

Удаляет **только** компоненты awg-warp: WARP-туннель и AWG-интерфейсы, созданные этим скриптом (определяются по маркерам `.awg_iface_*`). Сторонние AWG-серверы в `/etc/amnezia/amneziawg/` **не затрагиваются**.

> Пакеты системы (`wireguard-tools`, `amneziawg-go`, `awg`) не удаляются.

## Диагностика

### Пользователь создаётся, но не подключается

`awg-manager` всегда сохраняет конфиг клиента в `/root/awg-warp/<имя>.conf`, даже если применить его к «живому» интерфейсу не удалось. Если при создании пользователя видишь предупреждение вида:

```
WARNING: interface awg0 is not up — config saved but not applied live.
```

значит сам AWG-интерфейс не поднят (частая причина — `awg-quick up` упал при установке). Проверь:

```bash
awg show                                   # должен показать интерфейс и пиров
awg-quick up awg0                          # поднять вручную (подставь своё имя awgN)
systemctl status awg-quick@awg0
journalctl -u awg-quick@awg0 --no-pager | tail -30
```

После того как интерфейс поднялся, пересоздавать пользователей не нужно — примени конфиг заново:

```bash
awg syncconf awg0 <(awg-quick strip awg0)
```
